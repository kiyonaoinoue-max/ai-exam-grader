# 🎓 AI答案採点Webシステム (AI Exam Grading System)

スキャンした答案用紙（PDF）と模範解答・配点マスタを照合し、Google Geminiによる自動採点・セクション集計・Excel出力を行うWebアプリケーションです。

---

## 🌟 主な機能と特徴

1. **受験者名簿の一括登録 ＆ 自動ナンバリング**:
   - Excelの「氏名列」をコピー＆ペーストするだけで、開始番号（例: `1001`）から自動で受験番号を採番。
2. **まとまったスキャンPDFの自動ページ分割**:
   - 「1人あたりの枚数（1枚、2枚、3枚…）」を指定するだけで、生徒ごとに自動分割。
3. **【第1回目視確認】 受験番号・スキャン照合UI**:
   - 外国人の手書き数字の癖（1と7、0と6など）やスキャン抜けを防止するため、答案プレビューを見ながら番号・氏名を目視チェック＆サクサク修正（キーボード `Enter` や `Ctrl+→` で次へ）。
4. **AI自動採点（Google Gemini API連携）**:
   - **記号・単答問題**: 厳密に照合・判定。
   - **数学Iの数式問題**: 分数、根号（ルート）、因数分解、二次方程式、頂点座標などの表記揺れ・同値変形を賢く判定。
   - ※Gemini APIキー未設定でも、UIと帳票出力を体験できる「デモ用モック採点」機能を搭載。
5. **【第2回目視確認】 最終採点レビュー＆手動修正**:
   - 答案画像とAIの判定結果を横並びで確認。
   - `○ 正解` `△ 部分点` `✕ 不正解` や得点ボックスをクリックするだけで、セクション小計・総合得点が即座に自動再計算。
6. **Excel（.xlsx）エクスポート**:
   - 受験番号、氏名、総合得点、各大問（セクション）の小計、各問の正誤・配点、平均点を含んだ一覧表をワンクリックでダウンロード。

## 📝 使い方ステップ

1. **ステップ1: 名簿・配点設定**
   - 氏名を貼り付けて「自動ナンバリング生成」をクリック（または「サンプル名簿読込」）。
   - 大問・小問・配点・模範解答を設定（または「数I・記号サンプル読込」）。
2. **ステップ2: PDF取込・分割**
   - 「1人あたりの枚数」を選択し、スキャンPDFをドラッグ＆ドロップ。
   - （手元にPDFがない場合は「テスト用サンプル答案を生成して試す」ボタンで即座に検証可能）
3. **ステップ3: 【第1回目視確認】番号照合**
   - 答案ヘッダーの手書き番号を目視確認し、`Enter` で次々確定。
4. **ステップ4: AI自動採点実行**
   - 「AI自動採点を一括スタート」をクリック。
5. **ステップ5: 【第2回目視確認】採点レビュー**
   - 各設問の判定結果を確認。必要に応じて○/△/×をワンクリック修正。
6. **ステップ6: Excel出力**
   - 「Excelダウンロード (.xlsx)」をクリックして成績表を取得。
